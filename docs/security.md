# 보안 및 주의사항

이 프로젝트는 Velog 내부 GraphQL API를 리버스 엔지니어링한 비공식 도구입니다. Velog가 API를 바꾸면 예고 없이 일부 또는 전체 기능이 멈출 수 있습니다.

## 토큰

- 토큰은 `~/.velog-mcp.json`에 `0600` 권한(본인만 읽기·쓰기)으로 저장됩니다. 이 파일은 커밋하거나 공유하지 마세요.
- `access_token`과 `refresh_token`이 함께 노출되면 다른 사람이 내 Velog 계정을 그대로 쓸 수 있습니다. 노출이 의심되면 Velog에서 다른 기기 세션을 종료하고 다시 로그인한 뒤, `npx -p velog-mcp-claude velog-mcp-setup`으로 새 토큰을 저장하세요.
- 서버는 내 컴퓨터에서만 실행되고(stdio), 토큰은 Velog API 호출에만 씁니다. 단 `npx`로 실행하면 npm에 올라간 패키지를 그대로 실행하므로, 그 패키지를 신뢰한다는 전제가 있습니다.

## 되돌리기 어려운 작업

다음 작업은 Claude가 호출하기 전에 내용을 직접 확인하고 승인하세요.

| 툴 | 이유 |
| --- | --- |
| `velog_delete_post` | 포스트가 영구 삭제됩니다. |
| `velog_delete_comment` | 댓글이 영구 삭제됩니다. |
| `velog_publish_post` (공개) | RSS·검색으로 퍼진 뒤에는 비공개로 돌려도 완전히 회수되지 않습니다. |

**초안 미리보기 카드의 발행 버튼**

- 카드에서 **발행하기**를 누르는 것은 사용자가 직접 발행을 확인한 것으로 봅니다.
- 공개 발행은 두 번 눌러야 하고, 더블클릭이나 키를 누르고 있는 것으로는 두 번째 확인이 되지 않습니다.
- 본문의 HTML은 실행되지 않도록 걸러서 보여 줍니다. 다른 사람이 쓴 글을 가져와도 카드 안에서 스크립트가 돌지 않습니다.
- 카드에서 누른 발행을 Claude 앱이 한 번 더 승인받는지는 앱마다 다르고 확인되지 않았습니다.
- 구현 상세는 [overview.md](./overview.md)를 보세요.

## 사용 범위

- 본인 계정으로, 정상적인 블로그 활동 범위에서만 쓰세요.
- 짧은 시간에 대량 발행하거나, 다른 사람 글에 댓글을 반복해서 다는 자동화는 Velog 이용약관에 걸리거나 계정 제재로 이어질 수 있습니다.
- 다른 사람의 토큰을 쓰거나, 토큰을 코드·환경변수에 하드코딩하지 마세요.

## 문제가 생기면

| 증상 | 원인 | 해결 |
| --- | --- | --- |
| 모든 툴에서 인증 오류 | 토큰 만료 (`refresh_token` 약 30일) | `npx -p velog-mcp-claude velog-mcp-setup` 다시 실행 |
| 특정 툴만 오류 | Velog API 변경 | [GitHub Issues](https://github.com/seongwon030/velog_mcp/issues)에 제보 |
| 발행 직후 글 주소가 504 | Velog 페이지 반영 지연 | 1~2분 뒤 다시 열거나 Velog 내 글 목록에서 열기 |
| 발행했는데 남에게 안 보임 | 비공개(`is_private: true`)로 발행됨 | Velog에서 공개 여부 확인 |
| 초안이 사라짐 | 초안은 서버 메모리에만 있어 재시작하면 사라짐 | 보존하려면 비공개로 발행 |
